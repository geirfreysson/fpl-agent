# FPL Data Structure Documentation

This document describes the data structure of all parquet files generated by `process_fpl_data.py`.

## Overview

The FPL data processing script converts JSON data into normalized files for efficient analysis:

- **Source Files**: `bootstrap_static.json`, `fixtures.json`, `player_summaries.json`
- **Output Files**: 4 parquet files + 1 JSON file with normalized, analytics-ready data
- **Total Records**: 3,202 records across all files
- **Memory Efficient**: Load only the data you need for specific analyses

## File Structure

```
fpl_data/
├── elements.parquet           # Player basic information and stats
├── fixtures.parquet           # Match fixtures data
├── player_fixtures.parquet    # Player-specific fixture data
├── player_history_past.parquet # Historical season performance
└── teams.json                 # Premier League teams data
```

## 1. elements.parquet

**Source**: `bootstrap_static.json` → `elements` section  
**Records**: 663 players  
**Columns**: 97 columns  

### Key Columns

#### Player Identity
- `id` (int64): Unique player ID
- `first_name` (str): Player's first name
- `second_name` (str): Player's last name
- `web_name` (str): Display name used in FPL
- `code` (int64): Player code
- `element_type` (int64): Position type (1=GK, 2=DEF, 3=MID, 4=FWD)

#### Team Information
- `team` (int64): Team ID
- `team_code` (int64): Team code
- `squad_number` (str): Jersey number
- `status` (str): Player status (available, injured, etc.)

#### Cost & Ownership
- `now_cost` (int64): Current price (in 0.1m units, e.g., 55 = £5.5m)
- `cost_change_event` (int64): Price change this gameweek
- `cost_change_start` (int64): Price change since season start
- `selected_by_percent` (str): Ownership percentage

#### Performance Stats
- `total_points` (int64): Total FPL points this season
- `event_points` (int64): Points scored in latest gameweek
- `form` (str): Average points per game over last 5 games
- `points_per_game` (str): Average points per game this season
- `minutes` (int64): Total minutes played
- `goals_scored` (int64): Goals scored
- `assists` (int64): Assists provided
- `clean_sheets` (int64): Clean sheets (GK/DEF)
- `goals_conceded` (int64): Goals conceded (GK/DEF)
- `saves` (int64): Saves made (GK)
- `yellow_cards` (int64): Yellow cards received
- `red_cards` (int64): Red cards received
- `bonus` (int64): Bonus points earned
- `bps` (int64): Bonus points system score

#### Advanced Metrics
- `influence` (str): Influence rating
- `creativity` (str): Creativity rating
- `threat` (str): Threat rating
- `ict_index` (str): Combined ICT index
- `expected_goals` (str): Expected goals (xG)
- `expected_assists` (str): Expected assists (xA)
- `expected_goal_involvements` (str): Expected goal involvements
- `expected_goals_conceded` (str): Expected goals conceded

#### Availability
- `can_transact` (bool): Can be bought/sold
- `can_select` (bool): Can be selected in team
- `chance_of_playing_next_round` (float): Injury probability (0-100)
- `news` (str): Latest news/injury updates

## 2. fixtures.parquet

**Source**: `fixtures.json`  
**Records**: 380 fixtures  
**Columns**: 17 columns  

### Key Columns

#### Match Identity
- `id` (int64): Unique fixture ID
- `code` (int64): Match code
- `event` (int64): Gameweek number
- `pulse_id` (int64): Pulse ID

#### Teams
- `team_h` (int64): Home team ID
- `team_a` (int64): Away team ID
- `team_h_score` (object): Home team score (null if not played)
- `team_a_score` (object): Away team score (null if not played)

#### Timing
- `kickoff_time` (str): Match kickoff time (ISO format)
- `minutes` (int64): Minutes played (0 if not started)
- `started` (bool): Whether match has started
- `finished` (bool): Whether match is finished
- `provisional_start_time` (bool): If start time is provisional

#### Difficulty
- `team_h_difficulty` (int64): Home team difficulty rating (1-5)
- `team_a_difficulty` (int64): Away team difficulty rating (1-5)

#### Match Data
- `stats` (object): Match statistics (empty list if not played)

## 5. teams.json

**Source**: `bootstrap_static.json` → `teams` section  
**Records**: 20 Premier League teams  
**Format**: JSON (not parquet - small, static lookup data)  

### Key Fields

#### Team Identity
- `id` (int): Unique team ID (1-20)
- `name` (str): Full team name (e.g., "Arsenal")
- `short_name` (str): 3-letter team code (e.g., "ARS")
- `code` (int): Team code
- `pulse_id` (int): Pulse identifier

#### League Position & Stats
- `position` (int): Current league position (0 if season not started)
- `played` (int): Games played
- `win` (int): Games won
- `draw` (int): Games drawn
- `loss` (int): Games lost
- `points` (int): League points
- `form` (null): Recent form (null if season not started)

#### Team Strength Ratings
- `strength` (int): Overall team strength (1-5 scale)
- `strength_overall_home` (int): Overall home strength rating
- `strength_overall_away` (int): Overall away strength rating
- `strength_attack_home` (int): Home attack strength
- `strength_attack_away` (int): Away attack strength
- `strength_defence_home` (int): Home defence strength
- `strength_defence_away` (int): Away defence strength

#### Team Status
- `unavailable` (bool): Whether team is unavailable
- `team_division` (null): Team division (null for Premier League)

### Usage Examples
```python
import json

# Load teams data
with open('fpl_data/teams.json', 'r') as f:
    teams = json.load(f)

# Create team lookup dictionary
team_lookup = {team['id']: team for team in teams}

# Get team name by ID
team_name = team_lookup[1]['name']  # "Arsenal"

# Get teams by strength
strong_teams = [team for team in teams if team['strength'] >= 4]

# Get home/away strength differences
for team in teams:
    home_advantage = team['strength_overall_home'] - team['strength_overall_away']
    print(f"{team['short_name']}: {home_advantage} home advantage")
```

## Data Relationships

### Joining Data
Use `player_id` to join player-specific data:

```python
import pandas as pd
import json

# Load data
elements = pd.read_parquet('fpl_data/elements.parquet')
player_fixtures = pd.read_parquet('fpl_data/player_fixtures.parquet')
player_history = pd.read_parquet('fpl_data/player_history_past.parquet')

# Load teams data
with open('fpl_data/teams.json', 'r') as f:
    teams_list = json.load(f)
teams_df = pd.DataFrame(teams_list)  # Convert to DataFrame if needed

# Join player info with fixtures
player_fixture_details = player_fixtures.merge(
    elements[['id', 'web_name', 'team', 'element_type']], 
    left_on='player_id', 
    right_on='id'
)

# Join player info with historical performance
player_performance = player_history.merge(
    elements[['id', 'web_name', 'element_type']], 
    left_on='player_id', 
    right_on='id'
)

# Add team names to player data
player_with_teams = elements.merge(
    teams_df[['id', 'name', 'short_name']], 
    left_on='team', 
    right_on='id', 
    suffixes=('', '_team')
)
```

### Key Relationships
- `elements.id` ↔ `player_fixtures.player_id`
- `elements.id` ↔ `player_history_past.player_id`
- `elements.team` ↔ `teams[].id` (team lookup)
- `fixtures.team_h/team_a` ↔ `teams[].id` (team lookup)
- `player_fixtures.team_h/team_a` ↔ `teams[].id` (team lookup)
- `fixtures.id` ↔ `player_fixtures.id` (match-level data)

## Memory Usage Tips

### Load Only What You Need
```python
# Load specific columns only
elements_basic = pd.read_parquet(
    'fpl_data/elements.parquet',
    columns=['id', 'web_name', 'now_cost', 'total_points']
)

# Filter while loading
expensive_players = pd.read_parquet(
    'fpl_data/elements.parquet',
    filters=[('now_cost', '>=', 100)]  # £10.0m+
)
```

### Efficient Queries
```python
# Use vectorized operations
top_scorers = elements[elements['total_points'] > 100]

# Use .query() for complex filters
good_fixtures = player_fixtures.query(
    'difficulty <= 3 and is_home == True'
)
```

## Data Types Reference

- **int64**: Integer numbers (IDs, scores, counts)
- **float64**: Decimal numbers (percentages, ratings)
- **bool**: True/False values
- **object**: Strings, mixed types, or null values
- **datetime**: Date/time values (stored as strings in ISO format)
